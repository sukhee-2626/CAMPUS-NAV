# Campus Navigator image assets

This folder contains the supplied map screenshots and the visual assets used by the Campus Navigator project.

| File | Purpose |
|---|---|
| `illustrated-campus-map.jpeg` | Original illustrated campus map showing the buildings, food court, cafeteria, gates, parking, and route thread. |
| `google-maps-route-context.png` | Supplied Google Maps route context between Sri Krishna Arts and Science College and SKCET. |
| `road-context-pins.png` | Supplied road-context screenshot showing map pins and route context. |
| `road-context-survey.png` | Supplied road survey reference screenshot. |
| `full-campus-road-context.png` | Supplied full-campus road-context view for field surveying. |
| `full-campus-map-context.png` | Supplied full-campus map reference. |
| `campus-navigator-aerial.jpg` | Supporting aerial campus visual used in the app. |
| `campus-navigator-walk.jpg` | Supporting campus-walk visual used in the app. |
| `campus-navigator-paper.jpg` | Supporting paper texture used in the app. |
| `campus-navigator-mark.png` | Campus Navigator compass-pin mark. |

The application continues to reference managed asset URLs for deployment. These local copies are included for GitHub documentation, design reference, and future asset migration.
